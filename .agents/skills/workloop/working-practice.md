Working practice:
- A writing cell runs the brief's acceptance, iterating on the narrowest test that covers the failure: one test, file or package. In a run of two or more lanes, run nothing broader: integrate runs the composed test once over the merged tree. In a one-lane run, run the run's --verify command once before submit. Outside a run, run a full suite only when the brief names it, once, before returning. A QA cell runs each scenario's own command, not a broad suite the brief does not name. When one acceptance run costs over a minute, say so in your result.
- A command that ends within 10 minutes runs in the foreground with a timeout that covers it (Claude Code's Bash defaults to 2 minutes; set timeout up to 600000). Start a server, a watcher or a longer command where your host can see and stop it, never in the foreground. Claude Code: a Bash call with run_in_background: true, its command ending in ; echo "exit=$?" (with set -o pipefail first when it is a pipeline). Codex: nohup sh -c '<cmd>; echo "exit=$?"' > <log> 2>&1 & echo $!, keeping the process number.
- Wait with a capped loop; macOS has no timeout command. A server is ready when for i in $(seq 60); do curl -sf <url> >/dev/null && break; sleep 2; done ends. In Claude Code you are told when a background call ends, with your next tool result, so keep working; when nothing is left, wait for its end marker with for i in $(seq 110); do grep -q '^exit=' <output> && break; sleep 5; done, run with Bash's timeout at 600000, and repeat until it shows.
- A browser check of more than a few steps is a Playwright script, run in one shell call as node - <<'JS' … JS from a folder where playwright resolves (the project when it depends on Playwright, otherwise a scratch folder after npm i playwright), asserting in code so a failure exits non-zero; rerun the same call after a fix. Use the Playwright MCP tools only for a check of a few steps or to find a page's selectors: each MCP action is a model turn, which made a 14-step check 34 s against 12 s for a script and 0.9 s for its rerun.
- Stop what you started before you return: TaskStop in Claude Code, kill on the process number in Codex. A background call outlives the cell that started it.
- A writing cell edits a file with its host's edit tool: Read, then Edit or Write in Claude Code; apply_patch in Codex. A shell script writes only the output a command generates; a source file written from the shell skips the post-edit hooks.
