# Session report — investigation

A long session with no diff: debugging or research. The findings are the whole
deliverable, and they die with the context window unless written down.

Lead with the frame that fits:

- **Debugging** — lead with the root cause: proximate and underlying.
- **Research** — lead with the question and the answer.

Then, either way:

1. **The question** — what was being investigated, and why.
2. **Findings** — the answer, root cause, or conclusion, each tied to the
   evidence that establishes it (the files, commands, or sources).
3. **Ruled out** — dead ends and why, so the next investigator skips them.
4. **Open questions, risks, and the recommended next step.**
