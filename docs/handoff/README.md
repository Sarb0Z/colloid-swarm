# Handoffs

One self-contained document per handoff, written when the user asks for one, so
the next session or person can continue without the conversation that produced
it. `.agents/playbooks/workflow-write.md` defines the contents: objective,
current state, evidence, decisions, limitations, remaining gates, and the exact
next action with any authorization it needs.

Name each file `YYYY-MM-DD-<subject>.md`. `example-handoff.md` shows the shape.
