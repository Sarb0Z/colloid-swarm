# Fold-ins D2: code review round 1

Unit D2 of `docs/handoff/2026-11-12-job-tracker-fold-ins.md`: every `test-*`
file under `.agents`, outside `node_modules`, `worktrees` and `mcp-servers`,
is a check in `.agents/check-all.sh` or called by one, unless an allowlist
entry gives its reason. Commit `c5afabf` (run `fold-d2`, lane `d2`) puts the
rule in `.agents/lint-suite.py`, which already fails when `check-all.sh` and
`ci.yml` disagree and runs in both, with rows in `.agents/test-owed.sh`. One
reviewer (opus) read the scope whole and its seams; Critical stakes, since it
changes a gate. F15's three tests were all reached before the change, so the
allowlist starts empty.

## Findings

| # | Sev | Finding | Evidence |
|---|---|---|---|
| 1 | P1 | `lint-suite.py` is itself a listed check, and its search reads every non-comment line of a listed check, so the `UNLISTED_TESTS` line counts as a call to each test it names: every real entry fails as "no longer describes an unlisted test". The rows miss it, since their fixture lists no copy of the lint | reproduced in a clone |
| 2 | P2 | Changing the success line's count to every walked test stays green: no row has an allowlist entry, where reached and found differ | reproduced |

| 4 | P2 | The allowlist rows `sed`-rewrite `^UNLISTED_TESTS = {}` and the `ROOT =` line of a copy, so a real entry or a dict over several lines turns them red for the wrong reason | inspection |
| 5 | P2 | `--script .agents/check-all.sh`, the default named explicitly, turns the tree check off with no word | inspection |
| 6 | P2 | `--root` on a folder that is no git repository raises a bare `CalledProcessError`, git's own message captured and hidden | reproduced |
| 7 | P2 | `test-owed.sh`'s seam header names no line for the walk and its reach | inspection |
