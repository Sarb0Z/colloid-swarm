## Dispositions

All four adopted in `16d1e75`, trailing `12e6d34`.

| # | Disposition |
|---|---|
| 1 | A `last 40 lines:` label follows the kept lines whenever any are kept |
| 2 | The pattern is `^\w*(Error|Exception)\b`: an `Error:` line and a bare exception name count, at the cost of a line such as `Error rate 0.1` on a failing run |
| 3 | A row prints `not ok 7 - x`, a noise line, `  note FAIL: y`, `Error: Cannot find module z` and `AssertionError` above 45 `ok` lines and requires exactly the four failure lines, in order, between the two labels |
| 4 | The docstring says what the text holds on a pass and on a failure |
| AMBIGUITY | Settled as (a): a failure that a closing summary repeats inside the tail shows twice, which keeps the summary whole |
| HANDOFF | Run by the lead: four mutants in scratch copies, the slice before the tail removed, the cap raised to 21, a passing run labelled, and the `not ok` form dropped. Three failed their rows at once; the passing-run mutant stayed green, because `check` prints nothing of a passing verify, so that row now reads the run's recorded `verified.tail` and fails on the mutant |
