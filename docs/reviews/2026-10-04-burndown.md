## Lead finding

`test-hosted-scripts.py` runs `git init` and `git commit` in a temporary directory. Under `git rebase -x`, Git exports `GIT_DIR`, so those commands reached the real repository and set `core.bare=true`. Ten other test files run git the same way. Fix: every such test clears the `GIT_*` variables first.
