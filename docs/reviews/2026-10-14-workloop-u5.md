## Lane probes

Claude Code 2.1.299 with haiku cells, run by the lanes. `SubagentStop` fires only on a normal finish. A stopped background cell fires `PostToolUse` `TaskStop` in its caller, where `task_id` is the cell's `agent_id`. An API error fires `StopFailure` with the cell's `agent_id`. Esc and a killed parent session fire nothing for the cell. `SessionEnd` fires on a finished or failed `claude -p` and on a closed terminal, with reason `other`, and on `/exit` and a double Ctrl-D, with reason `prompt_input_exit`. It does not fire on SIGKILL. It waited for a 6 s hook. The binary bounds it at 60 s and fires it on `/clear` and `/resume`. Claude Code locks every `EnterWorktree` worktree, and the lock outlives the session.
