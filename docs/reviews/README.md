# Review records

One file per hostile-review round worth keeping: the reviewer and model, the
conformance line, and each finding with its severity and the lead's
disposition. `.agents/playbooks/hostile-review.md` is the reviewer contract and
the disposition rules; a workloop review cites a file here as its `--reference`.

Name each file `YYYY-MM-DD-<subject>.md`. `example-review.md` shows the shape.
