## Unit 9 — lane `checks`

QA, with real ESLint 9, tsc and ruff and no stubs, reproduced the four
acceptance claims: a lane whose `node_modules` links to the main checkout
reports an ESLint error the `main` hook misses; a configured ruff with no
binary is named once in a session and again in a new one; a caller broken by
a signature change is reported, once; an unreadable `tsconfig.json` and a bad
option are reported. With no configuration at all both modes stay silent, but
check mode leaves an empty `.agents/.readout/checks-ledger.lock`, and every run
costs 0.82 s against `main`'s 0.58 s (median of 10, nothing configured).

Rulings on the reviewer's two ambiguities, by the lead: the rule for errors
outside the edited files covers tsc only, since pyright analyzes the edited
files alone; "once per session" means once per host session, through
`session_id` (finding 4). Departures judged by the reviewer: `O_EXCL` for the
first report is sound; Prettier having no check-mode run is acceptable, with
the adjacent silent path in finding 13.

The corrections are `5e8791b..8d400a7`, nine commits; the lane widened to
`test-codex.sh`, whose expected Codex payload gains `session_id`. Each new
row went red with its fix reverted. The lead accepted four departures from
the corrections as written:

- Row 1: an edit to the file that holds an error still reports that file's
  own error. Only the edits to other files go quiet.
- Row 13: `ruff check --fix` and `eslint --fix` exit 1 when findings remain,
  which check mode reports, so their advisory starts at exit 2.
- Row 6: one `checkers.py batch` process per run. A check-mode run costs
  0.19 s against `main`'s 0.12 to 0.13 s, and a write-mode run is level
  with `main` (median of 10, stub ruff).
- Row 15: the parsing moved to `check_reports.py` (70 lines), and
  `checkers.py` grew to 449 lines with the ledger and install fixes. The
  remaining split is filed with the rest of finding 15.

A second QA cell (sonnet) ran the corrected tip with tsc 7.0.2 and pyright
1.1.414. It passed every scenario:

- Rows 1, 2, 3 and 5 no longer reproduce.

  the real Claude adapter, with the project set to the main checkout and to
  the lane, and through the Codex adapter.
- The missing-ruff line reaches each new session id through both adapters,
  1, 0, 1 over sessions A, A, B.
- A repository with no configuration stays silent and gets no
  `.agents/.readout/`.
- The pip pyright wrapper's version notice goes to stdout and causes no
  finding.
