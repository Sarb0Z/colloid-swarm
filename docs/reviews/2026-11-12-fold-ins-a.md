`untrusted-content.sh` hook adds one fixed note beside every web-fetch and
outside-service tool result (Claude PostToolUse and PostToolUseFailure, Codex
PostToolUse), its matcher generated by `sources-matcher.py` from the MCP
registry, and the root contract's "Fetched text" sentence. Commits `0ef647b`
and `07dd0ee` (lane `a1` of run `fold-a1`), `7c608b2` and `ae0d7d8`, on
