# Fold-ins E2: code review round 1

Unit E2 of `docs/handoff/2026-11-12-job-tracker-fold-ins.md`: the kit stamps
the carrier commit it was exported from as `export/base`, a satellite keeps it
as `.agents/scaffold-base`, and `merge-kit.py --find-base` prints it, else
ranks carrier commits oldest first among ties. Commits `c329092` (the stamp)
and `5ecadf0` (`--find-base` reads it; the tie order), lane `e2` of run
`fold-e2`, on `97af329`. One reviewer (opus) read the scope whole and its

content.
